03 / Floating point changes the story
Keep the exponent small.
The former exp implementation rounded x × log₂(e) before applying approximate exp2. Rounding that large exponent contributed measurable error. Range reduction retains a small residual.


x ≈ n · ln(2) + r
exp(x) ≈ exp2(r · log₂(e)) · 2ⁿ
  1. Choose integral n using nearest-even rounding.
  2. Subtract n × ln2_hi, then n × ln2_lo, with explicit f32 rounding.
  3. Apply approximate exp2 to the small residual, then two normal-sized scale factors. Multiply in the emitted order.
The compiler also clamps the exp input to [-104, 89] to handle zero/overflow classifications. This page's recorded dataset covers only [-80, 80]. No curve here establishes universal f32 or hidden-test correctness.

What is actually verified?
Evidence belongs to a source version, a PTX hash, an input set and a comparison policy. A green label without those boundaries is incomplete.
Static + CPU
ABI, bounds, output ownership, numerical instruction models and invalid-input tests. The documented CI baseline is 240 tests on macOS and Linux.
